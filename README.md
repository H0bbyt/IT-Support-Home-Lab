# IT-Support-Home-Lab
# IT Support & Active Directory Home Lab
# Project Overview
This project documents hands-on experience building and managing a virtual IT environment using VMware Workstation Pro, Windows Server 2025, Active Directory, DNS, and Kali Linux.

# Lab Enviroment
Host: Acer Nitro 5, Windows 11, 16GB RAM
Hypervisor: VMware Workstation
Domain Controller: DC01
Domain: monster.test

Installed Kali Linux and Windows Server 2025
Configured static IPv4 networking
Installed Active Directory and DNS
Created the monster.test domain
Resolved an Administrator password prerequisite error
Created Employees, IT, HR, and Sales OUs
